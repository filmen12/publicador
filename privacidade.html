Política de Privacidade do Publicador

Última atualização: 28 de outubro de 2026 · Início

O Publicador é uma ferramenta privada, usada apenas pelo dono dos canais Ainimacao e Curioso Area51 para publicar os seus próprios vídeos no YouTube. Esta política explica que dados ele acessa e o que faz com eles.

Dados acessados

Com a autorização do dono da conta Google (OAuth), o Publicador usa os serviços da API do YouTube com estas permissões:

  • youtube.upload: enviar vídeos, títulos, descrições e miniaturas para o canal do próprio dono;
  • youtube.readonly: ler o estado de processamento e as estatísticas públicas dos vídeos do próprio canal.

Uso dos dados

Os dados servem apenas para publicar e agendar os vídeos do próprio canal e verificar se foram processados. Não são usados para publicidade, não são vendidos e não são compartilhados com terceiros.

Armazenamento

Os tokens de acesso ficam guardados apenas no computador do dono dos canais. O Publicador não tem servidor próprio e não envia esses dados a nenhum lugar além das APIs do Google.

Revogar o acesso

O acesso pode ser revogado a qualquer momento em myaccount.google.com/permissions. Ao revogar, os tokens guardados deixam de funcionar.

Serviços do Google e do YouTube

O Publicador usa os serviços da API do YouTube. Ao usá-lo, você concorda com os Termos de Serviço do YouTube, e os dados são tratados também segundo a Política de Privacidade do Google. O uso dos dados recebidos das APIs do Google segue a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado.

Privacy Policy (English)

Publicador is a private tool used only by the owner of the YouTube channels Ainimacao and Curioso Area51 to upload and schedule their own videos. With the account owner's OAuth consent it uses YouTube API Services with the youtube.upload scope (upload videos, titles, descriptions and thumbnails to the owner's own channel) and the youtube.readonly scope (read processing status and public statistics of the owner's own videos). The data is used only for that purpose; it is not used for advertising, not sold and not shared with third parties. Access tokens are stored only on the owner's own computer; there is no Publicador server. Access can be revoked at any time at myaccount.google.com/permissions. By using it you agree to the YouTube Terms of Service; see also the Google Privacy Policy. Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
